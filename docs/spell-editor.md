# 符卡资源编辑

「角色 → 符卡」与「角色 → Buff」分别编辑符卡和 Buff；「资产 → AssetBundle」管理包文件的加载声明。

这里编辑显示资源，不编写实际效果。新增符卡或 Buff 条目不会自动生成或触发效果，修改说明也不会改变效果；实际行为需要 Mod 代码支持。

- 符卡 ID 对应本包角色 ID；实现名是 Mod 已注册的效果标识，区分大小写，由开发者提供。例如 Mai 对应舞的符卡逻辑，不是可随意命名的显示名称。
- 红卡和黑卡分别填写名称、说明并选择或上传 PNG 立绘。预览仅显示图片，不模拟游戏宣言动画。
- 可设置立绘锚点；关闭自定义时省略该字段，使用 Mod 默认值。
- 特效包可选。选择已构建的 AssetBundle 文件后，需要添加对应声明；文件可以没有扩展名。
- Buff 可编辑 ID、名称、说明和图标；保留说明里的占位符。
- Mai 需要特效包与 Buff 11002、11003。编辑器检查声明和本包文件，预制件及实际效果仍由游戏核验。

导入、自动保存、导出、资源包对比均保留 `spells`、`buffs`、`assetBundles`。旧包缺少这些数组时按空列表处理。移动资产会更新立绘、图标和特效包引用；更改角色 ID 会同步符卡所属 ID。删除角色或 AssetBundle 声明后，应通过导出检查确认没有悬空引用。

AssetBundle 是 Unity 的资源容器，特效包是其一种用途。上传文件只把文件放入资源包；`assetBundles` 声明让 Mod 在启动时加载，符卡再通过 `vfxBundle` 引用已声明且加载成功的包。当前 Mod 主要读取特效预制件，声明不代表已支持任意音频、模型或场景的使用。
