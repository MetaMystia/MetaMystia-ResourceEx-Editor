# 原始素材地图适配

地图格式版本 2 保留原图集、Sprite 网格/UV、逐个 PPU、逐格变换、颜色、排序信息和原生碰撞。画布按数据绘制，不生成替代 PNG；切片容量为 100000。版本 1 仍可编辑。

导入后再导出应保留源记录和原资产字节。运行时捕获的 PNG 是 GPU 纹理读回结果，不等于原游戏安装包内压缩文件的字节副本。

原生碰撞显示轮廓，暂不支持顶点编辑。原始高度层保留贴图，此时标量坡度画笔禁用。特殊材质默认隐藏，可在画布显示选项中打开“特殊材质源图”检查图像；这不是材质效果复刻。用吸管吸取原始格子时会连同变换和颜色一起作为画笔。

博丽神社包含 PPU 48 和 100，两者均保留。模组当前仅接受活动的 `Sprites/Default` 材质，完整镜像包需继续补齐特殊材质后才能运行。动画、互动脚本及完整排序层级仍待对齐。

批量美术参考包使用 `artOnly: true`，允许不提供音乐和可用相机边界，并在页面明确提示不能直接安装游玩。原始网格允许外置锚点，UV边界容许百万分之一浮点误差。美术参考中的有限颜色值原样保留，不因超出0到1而改写源数据；异常记录须在导出报告中列出。
