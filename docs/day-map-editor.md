# 白天地图编辑

入口：打开资源包后，选择“场景与节点 → 白天地图”。对应 `ResourceEx.json` 的 `dayMaps`，格式版本为 `1`（原始素材为 `2`）。图片和 WAV 随资源包 ZIP 导出。

## 界面

编辑器占满导航栏以下的窗口，窄屏时画布在上、属性面板在下。

| 区域     | 内容                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 顶栏     | 地图切换、新建与删除；编辑内容：瓦片、装饰、坡面、碰撞、出生点、地图；地图检查、快捷键、撤销与重做 |
| 画布左上 | 当前内容可用的工具，以及笔刷尺寸、当前画笔、吸附步长等参数                                         |
| 画布右上 | 显示选项：网格、碰撞轮廓、坡面、淡化其他图层、游戏画面预览、特殊材质源图                           |
| 画布底部 | 光标坐标与格子、悬停内容；网格开关、缩放比例、定位                                                 |
| 右侧面板 | 随编辑内容切换：图层与瓦片库、实体列表与属性、坡面画笔、地图信息与相机音乐                         |

显示选项、吸附步长保存在本浏览器，只影响预览，不写入资源包。

## 制作流程

1. 新建地图。声明了 ID 段时从该段分配；未声明时从不受管理区域分配。最终 ID 与签名仍由导出检查和 Mod 校验。
2. 在“瓦片”中点“导入”，选择 PNG 或从资产中选择，也可以把 PNG 直接拖到画布上。卡片预览切分网格，显示将生成的块数和每块占地；不能整齐切分时提示调整尺寸。默认 48×48 像素对应一格，也可整张作为一个切片。
3. 在图层列表选择当前图层，在瓦片库选择画笔后绘制。瓦片库按图片分组，可筛选；Ctrl/⌘ 单击、Shift 单击或在图集视图中框选多块，可组成按原图排列的图章。
4. 在“坡面”中选坡度后绘制；在“碰撞”中用“绘制碰撞框”拖出矩形；在“出生点”“装饰”中用放置工具点击添加，再用选择工具拖动调整。
5. 在“地图”中设置名称、ID、描述、相机与背景音乐。相机范围可以在画布上拖出、拖动或调整控制点；“按美术范围推算”根据 16:9 视口给出中心范围。
6. 查看顶栏“地图检查”并导出资源包。游戏中通过 `/resourceex map goto <id> [出生点]` 进入，仍需实测行走和遮挡。

## 工具与操作

| 内容   | 工具                                                                 |
| ------ | -------------------------------------------------------------------- |
| 瓦片   | 查看格子（V）、画笔（B）、矩形（R）、填充（G）、橡皮（E）、吸管（I） |
| 坡面   | 画笔、矩形、填充、橡皮、吸管                                         |
| 装饰   | 选择（V）、放置装饰（P）                                             |
| 碰撞   | 选择（V）、绘制碰撞框（R）                                           |
| 出生点 | 选择（V）、放置出生点（P）                                           |
| 地图   | 调整相机范围（V）、绘制相机范围（R）                                 |

任何内容下都可用平移（H）。每种内容记住上次使用的工具。

| 操作                            | 行为                                                        |
| ------------------------------- | ----------------------------------------------------------- |
| 滚轮 / 触控板捏合               | 以光标为中心缩放；触控板双指滑动平移                        |
| 按住空格拖动 / 中键拖动         | 平移，任何工具下可用；触屏双指可缩放平移                    |
| 右键拖动                        | 画笔、矩形、填充下擦除当前图层或坡度                        |
| 按住 Alt 点击                   | 吸取瓦片或坡度；原始素材地图会同时吸取格子的变换和颜色      |
| Shift + 点击                    | 从上一笔的终点连成直线                                      |
| `[` / `]`                       | 缩小、放大笔刷（1×1 至 9×9）                                |
| Shift / Ctrl + 点击、空白处拖动 | 加选、减选、框选装饰、碰撞或出生点                          |
| 拖动实体或控制点                | 移动或调整大小，按吸附步长对齐；按住 Alt 临时取消吸附       |
| 方向键                          | 有选中项时按吸附步长微调（Shift 为 1 格），否则移动格子光标 |
| 回车                            | 在格子光标处使用当前工具                                    |
| Delete、Ctrl + D、Ctrl + A      | 删除、复制、全选当前内容的实体                              |
| 1–6                             | 切换编辑内容                                                |
| F、`+`、`-`、`0`                | 定位选中项或整张地图、放大、缩小、恢复 100%                 |
| Ctrl/⌘ + Z、Ctrl + Shift + Z    | 撤销、重做                                                  |
| Esc                             | 取消当前拖动，或清除选择                                    |
| `?`                             | 打开快捷键说明                                              |

快捷键只在焦点位于编辑器或页面空白处时生效，输入框和弹出菜单中不拦截按键。

一次笔划、一次拖动或一次属性修改对应一步撤销；最多保留当前地图的 100 步。文本与数值在失焦或回车时提交，Esc 还原。更换地图、重新载入或其他操作替换地图数据后，局部历史会清空。撤销图片导入会撤销切片定义，图片仍在资产管理中。

坡面画笔显示比例和换算角度，例如 `0.5 ≈ 26.6°`；画布上每个坡度格中的白线就是向右行走的方向，格子足够大时标注数值和角度。角度按 `atan(slope)` 换算，表示移动方向，不是海拔。

“切片设置”调整选中切片的键、裁剪、锚点和每格像素，会影响地图中所有使用该切片的位置；重命名切片键会同步更新格子和装饰的引用。

## 显示与性能

画布用 WebGL2 按图集批量绘制，平移和缩放只更新视图，不重建顶点；绘制时只重建被修改的图层。悬停、选择框、碰撞、坡度等辅助标记画在单独的覆盖层上。超过显卡纹理上限的图集按比例缩小后预览，UV 不变。浏览器不支持 WebGL2 时回退到 Canvas 2D，状态栏显示“兼容渲染”，大地图会明显变慢。

特殊材质默认不参与预览，可在显示选项中打开“特殊材质源图”查看原始贴图，这不是材质效果复刻。

## 数据对应

- `tiles` 保存切片定义，`layers[].cells` 保存稀疏格子。坐标右正、上正；PNG 切片为 `[左,下,宽,高]`，编辑器负责转换图片坐标。
- `pivot` 使用归一化锚点。地面通常为 `(0,0)`，树木常用脚部 `(0.5,0)`。`pixelsPerUnit` 决定实际世界尺寸。
- 在已有格子上画同一切片不改动该格；换成其他切片时去掉旧格的 `transform`、`color`、`active`、`shader`、`sortingValue`，避免沿用另一切片的偏移。用吸管从原始素材格子吸取时，画笔会带上这些属性。未知扩展字段始终保留。
- `objects` 是独立装饰，按脚部 Y 排序时顺序为 `-32×Y`，Y 限制在 ±1023。固定前景可放在 `Overlay` 图层。
- `height.cells[].slope` 范围为 `[-1,1]`。正值向右上坡，负值向右下坡；零或擦除表示平地。它改变移动方向，不生成图片、碰撞、海拔或桥上桥下通行。
- `collisions` 的 X/Y 为矩形中心，拖动和调整大小以左下角对齐吸附步长；出生点使用独立名称和方向。重命名默认出生点会同步更新其引用，删除默认出生点后改用第一个出生点。
- `camera.bounds` 限制相机中心，不等于图片外框。推算按 16:9、正交半高 7.5、相机 Y 偏移 +0.5：`[x0+13.333+1/32, y0+7+1/32, x1−13.333−1/32, y1−8−1/32]`；地图小于视口时收拢到中心并提示。其他画幅仍需在游戏中检查。
- 坐标经过取整去除浮点误差，例如 `0.30000000000000004` 保存为 `0.3`。

地图沿用工作区的自动保存、恢复、资产管理和 ZIP 导出，不另设保存格式。图片与切片、音频与引用一起提交；读取文件期间工作区变化会拒绝过期操作。支持包内路径和本包 `rex://` URI，跨包资源只保留引用并提示游戏内核验。

导入和编辑保留未修改的扩展字段。未知 `formatVersion` 只能查看，不能修改；未来版本如果改变已有字段类型，仍需要升级编辑器。

## 校验与范围

检查重复 ID、切片键、同层格子和出生点；检查坐标、坡度、尺寸、引用与容量。导出还读取实际图片尺寸，检查切片越界和 WAV 文件结构。出生点检查只覆盖中心与矩形，不证明完整角色碰撞体或整张地图可达。

未加入多层通行、传送面板、地图节点、采集物、NPC 或多边形碰撞。原生碰撞只显示轮廓，不能编辑顶点。画布是编辑预览，不运行 Unity 的物理和相机。

## 验证记录

### 2026-10 界面重做

在 CNB 开发机（Node 22、pnpm 10）完成。`tsc --noEmit`、Prettier 检查与 Next 静态构建通过；改动前的基线同样通过 `tsc`。浏览器为 Playwright 1.55 的 Chromium，开发机没有显卡，WebGL 由 SwiftShader 软件渲染。

- 从零创建地图：导入 384×144 PNG 得到 24 块，`rect` 为左下角原点；画笔、撤销与重做、矩形、右键擦除、填充、Alt 吸取、2×1 图章、坡面、碰撞框创建与拖动和控制点缩放、出生点放置与拖动、装饰放置与删除及撤销、相机推算与画布拖出和控制点调整、滚轮缩放、空格平移、方向键与回车绘制，共 35 项检查全部通过，控制台无错误或警告。
- 上传 WAV 后地图检查通过；导出 ZIP 中的地图 JSON 与自动保存内容一致，包含切片图片和音频；刷新页面后恢复相同地图。保存的 JSON 无重复或非整数格子、无缺失切片引用，版本 1 地图没有写入原始属性。
- 原始素材镜像包中的妙莲寺（13938 格、93 装饰、18 张图集）与旧版对比，按主线程耗时计：平移每次指针事件约 117 → 18 ms，悬停约 103 → 17 ms，在万格图层上绘制约 133 → 31 ms。新版滚轮缩放每帧中位数 16.7 ms。无显卡环境下页面合成本身约 100 ms 一帧，两版相同，未能测得真实显卡上的帧率。
- 桌面 1600×960、1280×800 与 390 像素窄屏布局，深浅两种主题均已截图检查。

未验证：真实显卡上的帧率、触屏双指缩放、Safari 与 Firefox、系统减少动画模式下的实际观感，以及把导出的 ZIP 安装进游戏。
