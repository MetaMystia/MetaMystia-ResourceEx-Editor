# 白天地图编辑

入口：打开资源包后，选择“场景与节点 → 白天地图”。对应 `ResourceEx.json` 的 `dayMaps`，格式版本为 `1`。图片和 WAV 随资源包 ZIP 导出。

## 制作流程

1. 新建地图，设置名称和 ID。声明了 ID 段时从该段选择；未声明时从不受管理区域选择。最终 ID 与签名仍由导出检查和 Mod 校验。
2. 导入 PNG，填写切片宽高和每单位像素数。默认 48×48 像素对应一格；也可把整张图片作为一个切片。不能整齐切分时会提示调整尺寸，不会丢掉边缘。
3. 选择显示图层、瓦片和画笔，在画布上拖动绘制。矩形工具使用当前瓦片铺满矩形，橡皮只删除当前层的格子。
4. 在坡面模式绘制正负坡度，在碰撞模式拖出矩形。出生点和装饰可点击放置，再编辑精确坐标。
5. 在“地图、相机与音乐”中设置默认出生点、相机中心范围和 WAV。前奏与循环可以使用同一个文件。
6. 检查地图提示并导出资源包。游戏中通过 `/resourceex map goto <id> [出生点]` 进入，仍需实测行走和遮挡。

## 操作

| 操作                             | 行为                                                       |
| -------------------------------- | ---------------------------------------------------------- |
| 中键拖动 / 平移模式              | 移动画布视口                                               |
| 放大、缩小、定位地图             | 调整预览，定位包含美术、碰撞及出生点的范围                 |
| 图层开关                         | 只改变编辑器显隐，不导出；隐藏层不能绘制                   |
| 画布方向键、空格                 | 移动格子光标、绘制当前格                                   |
| Delete                           | 擦除当前格或删除选中的出生点、装饰、碰撞                   |
| Escape                           | 取消当前笔划或清除实体选择                                 |
| Ctrl/Cmd+Z、Ctrl+Y / Cmd+Shift+Z | 画布聚焦时撤销、重做                                       |
| 碰撞画笔                         | 点击已有框选择；在空白处拖出新矩形                         |
| 碰撞矩形                         | 可以从已有框内部起笔，创建重叠碰撞                         |
| 出生点                           | 点击已有点选择，再点空白位置移动；“放置新的出生点”清除选择 |

一次笔划对应一次撤销；最多保留当前地图的 40 个修改步骤。更换地图、重新载入或其他操作替换地图数据后，局部历史会清空。撤销图片导入会撤销切片定义，图片仍在资产管理中；导出沿用现有引用收集规则。

坡面画笔同时显示比例和换算角度，例如 `0.5 ≈ 26.6°`。画布在格子足够大时标注已绘制角度，底部显示光标格子的坡度和角度；更换画笔不会改变已有格子。角度按 `atan(slope)` 换算，表示移动方向，不是海拔。

“导入图片到瓦片库”用于增加绘制素材；“瓦片图片设置”调整选中素材的裁剪、锚点和尺寸，会影响地图中所有使用该瓦片的位置。

## 数据对应

- `tiles` 保存切片定义，`layers[].cells` 保存稀疏格子。坐标右正、上正；PNG 切片为 `[左,下,宽,高]`，编辑器负责转换图片坐标。
- `pivot` 使用归一化锚点。地面通常为 `(0,0)`，树木常用脚部 `(0.5,0)`。`pixelsPerUnit` 决定实际世界尺寸。
- `objects` 是独立装饰，可按脚部 Y 排序。固定前景可放在 `Overlay` 图层。
- `height.cells[].slope` 范围为 `[-1,1]`。正值向右上坡，负值向右下坡；零或擦除表示平地。它改变移动方向，不生成图片、碰撞、海拔或桥上桥下通行。
- `collisions` 的 X/Y 为矩形中心；出生点使用独立名称和方向。重命名默认出生点会同步更新其引用。
- `camera.bounds` 限制相机中心，不等于图片外框。当前需要手动设置并在游戏视口中检查。

地图沿用工作区的自动保存、恢复、资产管理和 ZIP 导出，不另设保存格式。图片与切片、音频与引用一起提交；读取文件期间工作区变化会拒绝过期操作。支持包内路径和本包 `rex://` URI，跨包资源只保留引用并提示游戏内核验。

导入和编辑保留未修改的扩展字段。未知 `formatVersion` 不允许在画布编辑；未来版本如果改变已有字段类型，仍需要升级编辑器。

## 校验与范围

检查重复 ID、切片键、同层格子和出生点；检查坐标、坡度、尺寸、引用与容量。导出还读取实际图片尺寸，检查切片越界和 WAV 文件结构。出生点检查只覆盖中心与矩形，不证明完整角色碰撞体或整张地图可达。

未加入多层通行、传送面板、地图节点、采集物、NPC、自动相机适配或多边形碰撞。画布是编辑预览，不运行 Unity 的物理和相机。
