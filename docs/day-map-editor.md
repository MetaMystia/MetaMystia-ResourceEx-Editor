# 白天地图编辑

入口：打开资源包后，选择“场景与节点 → 白天地图”。对应 `ResourceEx.json` 的 `dayMaps`，格式为画布地图（`formatVersion: 3`），与 MetaMystia 的 `DayMapRegistry` 一致；其他版本只读。图片和 WAV 随资源包 ZIP 导出。

## 数据结构

画布地图按原版 `DaySceneMap` 的组成拆分，美术是整张大图，玩法数据单独描述：

| 内容               | 字段                                                                   | 对应原版                                       |
| ------------------ | ---------------------------------------------------------------------- | ---------------------------------------------- |
| 图层               | `layers`：名称、排序层、排序值、可选颜色、左下角像素坐标、图片         | Tilemap 层                                     |
| 物件模板           | `prefabs`：键、图片、锚点、每单位像素、排序层、排序值、按 Y 排序、碰撞 | 带 `SpriteRenderer` 或 `SortingGroup` 的预制体 |
| 物件               | `objects`：模板、位置、缩放（负值翻转）、可选名称                      | 预制体实例                                     |
| 碰撞               | `colliders`：`polygon`、`edge`、`box`、`circle`                        | 各类 Collider2D 与 `CompositeCollider2D` 轮廓  |
| 坡面               | `height.cells`                                                         | `HEIGHT_MAP`                                   |
| 出生点、相机、音乐 | `spawnMarkers`、`camera`（多边形）、`mapBGM`、`hideClock`              | 同名组件与字段                                 |

图片按 1024 像素切块保存为 `<dir>/<列>_<行>.png`，块自图片左上角起算，只保存非空块；边长上限 16384 像素。创作者只导入整张 PNG，切块由编辑器完成。不超过一块且不需要裁剪的 PNG 原样保存文件字节；其余经画布重新编码，半透明像素可能有 1/255 的取整差异。

世界坐标右正、上正。图层位置为整数像素，世界坐标 = 像素 / `pixelsPerUnit`（默认 48，与原版地面相同）。物件模板可以使用其他像素密度，原版部分光照与特效为 100。

## 界面

编辑器占满导航栏以下的窗口，窄屏时画布在上、属性面板在下。

| 区域     | 内容                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 顶栏     | 地图切换、新建与删除；编辑内容：图层、物件、碰撞、坡面、出生点、地图；地图检查、快捷键、撤销与重做     |
| 画布左上 | 当前内容可用的工具，以及笔刷尺寸、坡度、当前模板、吸附步长等参数                                       |
| 画布右上 | 显示选项：网格、碰撞轮廓、坡面、淡化其他图层、游戏画面预览                                             |
| 画布底部 | 光标坐标与格子、悬停内容；网格开关、缩放比例、定位                                                     |
| 右侧面板 | 随编辑内容切换：图层列表与属性、物件列表与模板库、碰撞列表与属性、坡面画笔、出生点、地图信息与相机音乐 |

显示选项与吸附步长保存在本浏览器，只影响预览，不写入资源包。

## 制作流程

1. 新建地图。声明了 ID 段时从该段分配；未声明时从不受管理区域分配。
2. 在“图层”中导入地面 PNG，或直接拖到画布上；新图层以视图中心或落点为中心。前景（树冠、屋檐）另导入一层，排序层设为 `Overlay`。在外部工具修改后用“替换图片”，左上角保持不动；“导出 PNG”把图块拼回整图。
3. 在“物件”中导入树木、房屋等 PNG，透明边自动裁掉，锚点默认在底部中央；物件模式下拖到画布上的 PNG 也作为模板导入。选中模板后用“放置物件”工具点击画布。
4. 在“碰撞”中绘制。实心形状挡住内部；折线只有线段阻挡，闭合后仍可在内部行走，适合围出可走区域（原版地图边界即此做法）。物件的“编辑模板碰撞”以该物件为锚点，碰撞保存在模板中，所有实例共用。
5. 在“坡面”中选坡度后绘制，在“出生点”中放置出生点。
6. 在“地图”中设置名称、ID、描述、隐藏时钟、相机与背景音乐。相机范围是多边形，可在画布上拖动顶点或整体，也可用多边形或矩形工具重画；“按美术范围推算”按 16:9 视口给出矩形。音乐可选包内 WAV，或填写原版 `LoopedBGMPackage` 地址（如 `DLC3_HakureiFestival`）。
7. 查看顶栏“地图检查”并导出资源包。游戏中通过 `/resourceex map goto <id> [出生点]` 进入，仍需实测行走和遮挡。

## 工具与操作

| 内容   | 工具                                                      |
| ------ | --------------------------------------------------------- |
| 图层   | 移动图层（V）                                             |
| 物件   | 选择（V）、放置物件（P）                                  |
| 碰撞   | 选择（V）、多边形（N）、折线（L）、矩形（R）、圆形（O）   |
| 坡面   | 画笔（B）、矩形（R）、橡皮（E）、吸管（I）                |
| 出生点 | 选择（V）、放置出生点（P）                                |
| 地图   | 编辑相机范围（V）、绘制相机多边形（N）、绘制相机矩形（R） |

任何内容下都可用平移（H）。每种内容记住上次使用的工具。

| 操作                            | 行为                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------ |
| 滚轮 / 触控板捏合               | 以光标为中心缩放；触控板双指滑动平移                                           |
| 按住空格拖动 / 中键拖动         | 平移，任何工具下可用；触屏双指可缩放平移                                       |
| 单击 / 双击 / 回车              | 多边形、折线与相机多边形逐点绘制，双击或回车结束                               |
| 单击起点                        | 闭合并结束；折线由此成为闭合折线                                               |
| 退格 / Esc                      | 撤销上一点、取消绘制                                                           |
| Shift + 多边形工具              | 选中一个多边形时，绘制结果作为洞加入该多边形                                   |
| 拖动顶点 / 双击边               | 移动顶点、在边上插入顶点（选中的多边形、折线或相机范围）                       |
| Delete（选中顶点）              | 删除顶点；路径少于最少顶点时删除该路径                                         |
| 拖动控制点                      | 调整未旋转矩形的大小、圆的半径                                                 |
| 右键拖动                        | 坡面画笔与矩形下擦除                                                           |
| 按住 Alt                        | 拖动或绘制时临时取消吸附；坡面下点击吸取坡度                                   |
| Shift / Ctrl + 点击、空白处拖动 | 加选、减选、框选物件、碰撞或出生点                                             |
| 方向键                          | 选中项按吸附步长微调（Shift 为 4 倍）；图层模式下按 1 像素（Shift 为 10 像素） |
| Delete、Ctrl + D、Ctrl + A      | 删除、复制、全选当前内容的实体                                                 |
| `[` / `]`                       | 缩小、放大坡面笔刷                                                             |
| 1–6                             | 切换编辑内容                                                                   |
| F、`+`、`-`、`0`                | 定位选中项或整张地图、放大、缩小、恢复 100%                                    |
| Ctrl/⌘ + Z、Ctrl + Shift + Z    | 撤销、重做                                                                     |
| `?`                             | 打开快捷键说明                                                                 |

快捷键只在焦点位于编辑器或页面空白处时生效，输入框和弹出菜单中不拦截按键。吸附步长默认 1 像素（1/48 格）。

一次拖动、一次逐点绘制或一次属性修改对应一步撤销；最多保留当前地图的 100 步。更换地图、重新载入或其他操作替换地图数据后，局部历史会清空。撤销图片导入会撤销图层或模板，图块文件仍在资产管理中。

## 显示与性能

画布用 WebGL2 绘制，每个图块一个四边形，按游戏顺序排列：排序层优先，同层按排序值，按 Y 排序的物件取 `(int)(-32×Y)`。几何体只在地图或资产变化时重建，平移缩放只更新视图；图块尺寸不超过 1024，所有显卡都能直接上传，缩小时使用 mipmap。辅助标记画在单独的覆盖层上。浏览器不支持 WebGL2 时回退到 Canvas 2D，状态栏显示“兼容渲染”。

## 数据对应

- 物件模板碰撞使用模板局部坐标（未翻转）；画布上按锚点物件的位置与缩放显示，编辑时自动换算。
- 资产移动或重命名时，图层和模板的图块目录随之改写；跨包 `rex://` 资源只保留引用并提示游戏内核验。
- 坐标经过取整去除浮点误差，例如 `0.30000000000000004` 保存为 `0.3`。
- 导入和编辑保留未修改的扩展字段。

## 校验与范围

检查格式版本、模板键重复与引用、排序层、坐标与像素位置、图块编号、碰撞形状、坡度格、出生点名称及是否落在实心碰撞内、相机多边形与音乐。导出时还读取每个图块的 PNG 头部，核对尺寸与图片配置一致，并检查 WAV 结构。规则与 Mod 加载校验一致；原版音乐地址只能在游戏中确认。

未加入特殊材质、动画、交互物、采集点、NPC 与出口。画布是编辑预览，不运行 Unity 的物理和相机。原版地图镜像见 [native-day-map.md](native-day-map.md)。

## 验证记录

### 2026-10 画布地图

本机 Node 22、pnpm 10；`tsc --noEmit`、Prettier 检查与 `git diff --check` 通过。浏览器为 Playwright 1.64 的无头 Chromium，WebGL 由 SwiftShader 软件渲染，开发服务器只绑定 127.0.0.1。

- 导入博丽大祭镜像包（2 个图层 22 块、70 个模板 89 个物件、14 个地图碰撞与 2 个模板碰撞、41 个坡度格）：六种编辑内容均正常显示，地图检查通过，控制台无错误或警告。
- 交互：多边形、折线、矩形、圆形绘制；拖动顶点、双击插入、Delete 删除、撤销；物件微调；以物件为锚点添加模板碰撞并返回；放置出生点；坡面画笔；拖动图层。共 14 项检查全部通过。
- 导入 4560×4080 PNG 为新图层得到 20 个图块；导入 300×260 的带透明边 PNG 为模板，裁剪为 181×201 并放置。
- 用 `tsx` 运行编辑器自身的读取、导出视图与编辑函数：镜像包读取后校验为空，导出视图与原 JSON 一致，127 个文件全部被引用；改动后的包通过 MetaMystia `dayart.validate` 离线校验。
- 桌面 1600×960、1280×800 深色主题与减少动画、390 像素窄屏均已截图检查。

未验证：浏览器内“导出资源包”的下载（本机无头环境中，不含地图的示例资源包同样没有触发下载）、真实显卡上的帧率、触屏、Safari 与 Firefox，以及把编辑器导出的 ZIP 安装进游戏。
